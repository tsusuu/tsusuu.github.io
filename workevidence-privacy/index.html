1. 적용 범위와 지원 문의

이 방침은 근무노트 iOS 앱(com.tsusuu.workevidence)에 적용됩니다. 기기에 보관하는 근무 자료와 지도·광고·문의 과정의 외부 처리를 설명합니다. 현재 제공되는 비개인화 데모 광고 설정을 기준으로 하며, 운영 광고나 맞춤형 광고를 제공한다는 뜻은 아닙니다.

운영자와 개인정보 문의 담당자는 개인 최영서입니다. 지원이나 개인정보 열람·정정·삭제·처리정지가 필요하시면 help@devsworker.com으로 문의해 주세요. 앱 버전과 문제가 생긴 화면, 재현 방법을 적고 필요한 부분만 첨부해 주세요. 주민등록번호·건강정보·타인의 연락처나 전체 근무 자료는 보내지 마세요. 문의는 선택 사항이며, 보내지 않아도 로컬 기능을 이용할 수 있습니다. 문의 메일은 iCloud Mail에서 받고 답변·문제 해결에 사용하며, 처리 완료 후 1년 동안 보관한 뒤 삭제합니다.

이 앱은 대한민국의 만 15세 이상 이용자를 대상으로 합니다. 생년월일이나 신분증으로 연령을 확인하지는 않습니다. 대상 연령의 안내가 연령 확인이나 법정대리인 동의를 대신하지 않습니다.

2. 기기에 보관하는 근무·사진·급여 자료

근무 프로필·근무지·일정·급여 조건·수당·공제·보정·메모·태그와 변경 이력은 일정 관리 및 근무시간·예상 급여 계산에 사용합니다. 세금 유형, 공제대상 가족·자녀 수, 원천징수 비율과 비과세 급여 등 입력 조건도 기기에서 계산에 사용합니다. 초기 추정값이 실제 가족·과세 조건을 확인했다는 뜻은 아니므로 본인 상황에 맞게 확인해 주세요.

출퇴근 사진·촬영 시각·연결 일정·위치·정확도·기록 해시와 서명은 출퇴근 기록 및 변경 확인에 사용합니다. 근로계약서 이미지·PDF와 급여명세서 인식 결과는 해당 문서의 관리·검토에 사용합니다. 위치 좌표·관측 시각·정확도와 근무 연결 정보는 경로·체류·근무지 이탈 상태를 확인하는 데 사용합니다.

일정표 사진은 기기에서 사용 가능한 Apple Foundation Models와 Apple Vision으로 인식합니다. AI 추출을 이용할 수 없거나 실패하면 Vision 문자 인식으로 전환합니다. 계약서·급여명세서 등의 문자 인식도 기기에서 처리합니다. 앱은 이 사진이나 모델 입력을 AI 서버에 업로드하지 않습니다. 지도 요청과 이용자가 선택하는 공유는 별도입니다.

회원 계정 서버나 근무 자료를 자동 업로드하는 운영자 서버는 없습니다. 앱에서 기록을 확인·수정하거나 필요한 자료만 내보내 주세요. 기기와 별도로 보관한 사본은 이용자가 관리해야 합니다.

3. 권한과 위치 기록을 선택하는 방법

카메라는 이용자가 출퇴근 사진이나 문서를 촬영할 때 사용합니다. 알림은 선택한 근무 안내에, 생체 인증은 선택한 앱 잠금에 사용합니다. 위치 권한은 iOS 설정에서 변경하거나 철회할 수 있습니다. 권한이 없어도 수동 일정·주소 입력은 가능하지만 해당 촬영·GPS 기능은 제한됩니다.

사진 촬영 또는 ‘사진 없이 출근’으로 실제 출근을 기록하면 연결된 위치 추적이 백그라운드·화면 잠금 중에도 이어질 수 있고 iOS 위치 표시가 나타납니다. 퇴근 처리, 위치 권한 차단 또는 시간 제한에 따라 중단됩니다. 기록 시간 제한은 예정 종료 후 2시간과 출근을 처음 확인한 시각 후 50시간 중 이른 시각입니다. GPS 일시중지는 위치 기록을 멈추지만 퇴근 처리는 하지 않습니다.

사진 없는 예정 근무 자동 GPS는 기본으로 꺼져 있습니다. 안내를 확인하고 켠 경우에만 예정 시작 이상·종료 미만 구간의 조건을 확인해 위치 기록을 시도합니다. iOS 백그라운드 실행 기회를 이용하며 근무 밖에서 위치를 받으면서 시작을 기다리지 않습니다. 예정 시각의 실행·강제 종료 중 동작·실제 위치 수신은 보장되지 않습니다. 앱을 열면 현재 근무·권한·기기 동의·저장 상태를 다시 확인합니다. 자동 GPS만으로 실제 출퇴근이나 급여 인정이 처리되지는 않습니다.

기본 모드에서는 약 60초 간격으로 실제 관측을 기록하고 의미 있는 이동은 최소 15초 간격으로 반영합니다. 휴게 중이나 선택한 시작 시각 전에는 경로 좌표를 저장하지 않지만 재개용 저전력 위치 세션과 iOS 표시가 유지될 수 있습니다. 절약 모드·수신 상태·iOS에 따라 간격이나 연속성이 달라지며 오래된 좌표로 공백을 채우지 않습니다. 지도에서 관측을 체류로 묶는 표시는 원본 좌표를 지우거나 공백 동안의 체류를 증명하지 않습니다.

‘사진 없이 출근·퇴근’은 누른 시각을 실제 출퇴근으로 저장해 시간·급여 계산에 사용하되 사진 증빙은 남기지 않습니다. GPS를 시작하지 못해도 저장한 출근 기록은 취소되지 않고 별도 안내가 표시됩니다. 예정 근무 자동 GPS 설정과는 별개의 선택입니다.

자동 GPS 등 자동 옵션의 동의는 기기 전용 Keychain 확인값과 대조합니다. 다른 기기이거나 확인할 수 없으면 자동 옵션을 끄고, 복원이 중단되면 복원 또는 초기화 완료까지 자동 기능을 차단합니다. 이 동의 설정은 관리형 JSON 백업에 넣지 않습니다. 최근 실행·관측 수락·제외 상태는 기기에 보관하며 좌표·사진·급여를 운영자에게 자동 전송하는 진단 기능은 아닙니다. 원치 않으시면 자동 옵션을 끄거나 이번 근무의 GPS를 일시중지하고 iOS 위치 권한을 변경해 주세요. 권한 철회만으로 이전 기록이 삭제되지는 않습니다.

4. Apple 지도와 공휴일 정보

Apple 지도 검색·자동완성·장소 조회·역지오코딩을 이용할 때 검색어·장소 ID·지도 영역·좌표와 요청에 필요한 네트워크 정보가 Apple 지도 서비스로 전달될 수 있습니다. 현재 위치나 지도 지점의 주소를 찾을 때 반올림하지 않은 좌표를 전달합니다. 전체 GPS 경로를 운영자 서버에 업로드하는 기능과는 다릅니다.

장소 조회 결과는 지도 표시와 근무지 확인에 필요한 동안 메모리에서 사용합니다. 이용자가 직접 입력한 설명과 기기 GPS 좌표는 별도로 저장합니다. ‘현재 GPS 위치로 지정’하여 좌표를 저장하는 동작 자체는 역지오코딩 요청을 보내지 않습니다. 외부 조회를 원하지 않으면 지도 검색·주소 찾기 대신 직접 입력해 주세요.

새 출퇴근 사진과 PDF에는 촬영 시각과 기기 좌표를 표시하며 Apple 주소를 추가로 조회하지 않습니다. 공휴일 날짜는 앱에 포함하고 외부 공휴일 서버에 자동 접속하지 않습니다. 정정 사항은 앱 업데이트로 반영합니다.

5. 현재 광고 설정과 개인정보 선택

현재 앱은 Google Mobile Ads(GMA)의 공식 네이티브·전면 데모 광고 단위만 사용하고 모든 요청에 비개인화 설정(npa=1)을 적용합니다. 게시자 퍼스트파티 ID 사용은 끕니다. UMP 갱신 성공, 요청 가능 상태와 앱 전경 등 조건을 충족할 때만 요청합니다. 실제 운영·맞춤형 광고는 활성화하지 않았으며, 데모 설정이 광고의 실제 표시나 외부 처리의 부재를 보장하지 않습니다.

광고 SDK는 IP 기반 대략적 위치, 기기·앱 범위 식별자, 광고 표시·상호작용, 제품 사용, 충돌·성능·기타 진단 정보를 광고 제공·측정·분석 등에 처리할 수 있습니다. 배포 앱의 GMA manifest는 일부 위치·광고·제품 상호작용·기기 ID의 연결을 선언하고 기기 ID에는 추적 용도도 선언합니다. 비개인화·데모라는 이유만으로 ‘수집 없음’이나 ‘추적 없음’으로 단정하지 않습니다. 앱은 근무 사진·계약서·급여·메모·정밀 GPS 경로·PIN·서명 키를 광고 요청의 추가 데이터로 넣지 않습니다.

Google User Messaging Platform(UMP)은 지역별 개인정보 선택과 동의 상태를 관리합니다. 포함된 manifest에는 대략적 위치·성능·제품 상호작용의 앱 기능 제공 목적 처리가 선언되어 있습니다. UMP의 요청 가능 상태가 모든 맞춤형 광고 동의를 의미하지는 않습니다. 갱신에 실패하거나 요청 조건을 충족하지 못하면 광고를 요청하지 않으며 근무 기록·파일 내보내기는 계속 사용할 수 있습니다.

설정 → 앱 정보 → 광고 방식에서 저장된 광고 선호와 현재 적용 상태를 확인해 주세요. 선호를 바꿔도 현재 데모 전용 설정에서는 비개인화만 적용됩니다. Google이 개인정보 선택 화면이 필요하다고 판단한 경우에만 ‘Google 광고 개인정보 선택’이 표시됩니다. 이용 가능한 화면에서 선택을 확인·변경할 수 있습니다.

‘iOS 추적 설정 열기’는 앱의 iOS 설정을 엽니다. 광고 선호·Google 동의와 iOS 추적 권한은 별개이며 광고 선호 선택만으로 iOS 권한이 철회되지 않습니다. 현재 데모 경로의 광고 방식 선택은 앱의 ATT 권한 요청을 실행하지 않고, ATT가 미결정인 비개인화 경로에서는 최초 UMP 화면도 자동 표시하지 않습니다. 앱 코드는 IDFA 원시 값을 직접 읽거나 기록하지 않습니다. 이 설명이 SDK 처리를 모두 중단한다는 뜻은 아닙니다.

광고 환경 확인에는 StoreKit 설치 거래 검증 결과의 배포 환경과 앱 식별자를 사용합니다. 앱은 결제·구독을 제공하지 않으며 이 확인을 구매 이력 수집으로 사용하지 않습니다.

6. 백업·공유·잠금화면 표시

파일·PDF·백업을 내보낼 때 이용자가 고른 파일 제공자나 수신자에게 선택한 자료가 전달됩니다. 암호화 백업은 이용자가 정한 암호로 보호합니다. 저장·공유를 원하지 않으면 전송 전에 취소해 주세요. 외부 클라우드를 선택하면 그 서비스의 업로드·보관·국외 처리 정책이 적용됩니다.

앱 자체의 자동 서버 동기화·서버 복구는 제공하지 않습니다. iOS 기기 백업이나 이용자가 선택한 클라우드 사본은 앱 내부 저장과 별도이므로 iOS·서비스 설정도 확인해 주세요. 위젯과 실시간 현황에는 근무명·시간·상태·예상 금액 요약이 잠금화면이나 지원되는 연결 기기에 표시될 수 있으므로 iOS 표시 설정을 관리해 주세요.

7. 보관기간과 삭제

기기 자료의 기본 보관 설정은 ‘직접 지울 때까지’입니다. 저장 상태 및 보존에서 90일·180일·1년 기준의 정리 대상을 확인할 수 있습니다. 정리 대상은 화면에 표시되는 사진·GPS·이벤트 등이며 모든 자료가 같은 시점에 자동 삭제되는 것은 아닙니다. 법적으로 필요한 근로·세무 자료는 해당 기준에 따라 별도로 보관해 주세요.

개별 삭제·정리는 관련 기록·파일·색인을 삭제합니다. 내부 복구용 백업과 내보낸 사본에는 이전 자료가 남을 수 있으므로 사본도 별도로 관리해 주세요. 앱 정보의 모든 기록 초기화는 앱 내부 근무 자료·사진·위치·계약서·내부 백업·기록 서명 키를 삭제하지만 앱 PIN·생체 인증·잠금 설정과 외부 사본까지 지우는 기능은 아닙니다. 앱을 제거해도 일부 Keychain 항목이 남을 수 있습니다.

8. 선택적으로 보내는 지원 정보

메일을 보내면 운영자는 발신 주소·본문·선택한 첨부를 받아 답변과 문제 해결에 사용합니다. 앱 정보에서 선택하는 분석용 로그에는 생성 시각·앱 버전·OS와 버전·기기 종류·선호 언어가 들어가며 근무 자료·사진·GPS·암호·서명 키를 자동 첨부하지 않습니다. 메일 작성 화면에서 본문과 첨부를 확인한 뒤 직접 전송해 주세요. 메일 작성 기능을 쓸 수 없으면 진단 첨부 없이 이메일 링크를 엽니다.

운영자가 받은 문의와 첨부파일은 처리 완료 후 1년 보관한 뒤 삭제합니다. 이 기준은 기기의 근무 자료나 제공자 자체 보관기간을 바꾸지 않습니다. 문의 자료의 삭제 등 권리 행사는 help@devsworker.com으로 요청해 주세요.

9. 외부 제공자와 국외 처리

지도 조회·광고 및 동의 서비스·지원 메일·선택한 클라우드 저장에는 국외 서버 처리가 포함될 수 있습니다. 아래에서 계약 법인의 소재지와 실제 처리 장소를 구분합니다. 근무 자료 전체를 운영자 서버로 보내는 구조는 아닙니다.

Google 광고·동의 서비스: 확인된 계약 상대는 Google Asia Pacific Pte. Ltd.(싱가포르)입니다. 광고·UMP 요청 시 네트워크로 5절의 항목을 처리합니다. 목적은 광고 제공·측정·분석과 개인정보 선택 기능입니다. Google은 전 세계 서버와 계열사 등의 처리를 안내하지만 현재 공개 자료만으로 이 앱의 요청별 처리 국가 전체나 항목별 고정 보유 일수를 확인할 수 없습니다. 싱가포르만에서 처리된다고 보지 않습니다. 보관은 데이터 유형·이용 목적·보안 및 법적 필요에 따라 달라지며, Google의 특정 로그 익명화 예시를 모든 AdMob 자료의 삭제 기한으로 적용하지 않습니다. Google 개인정보 정책·보관 정책과 개인정보 선택 화면을 확인해 주세요.

Apple 지도: 지도·장소·주소 조회를 선택할 때 Apple 및 해당 서비스 제공자가 4절의 검색·위치·요청 정보를 네트워크로 처리합니다. Apple은 서비스 제공과 안전한 운영 등을 위한 국외 처리를 개인정보 정책에서 안내합니다. 이 앱의 개별 지도 요청에 적용되는 모든 서버 국가와 고정 보관기간은 확인되지 않았습니다. 주소를 직접 입력하면 해당 조회를 선택하지 않을 수 있습니다.

지원 메일: 이용자가 전송한 발신 주소·본문·첨부는 iCloud Mail을 통해 운영자에게 전달되어 답변·문제 해결에 쓰입니다. 한국 iCloud 약관은 Apple Services Pte. Ltd.를 서비스 계약 주체로 설명하며 싱가포르 소재 법인입니다. 콘텐츠는 Apple 또는 제3자 서버에서 처리될 수 있으나 이 메일함의 실제 저장 국가를 싱가포르로 단정하지 않습니다. 운영자의 보관기간은 처리 완료 후 1년이고, Apple 서비스의 보관·삭제 조건은 별도입니다. 메일을 보내지 않으면 이 문의 처리는 발생하지 않습니다.

사용자 선택 저장·공유: 내보내기 시 이용자가 고른 제공자·수신자가 선택 자료를 받습니다. 국가·보관·삭제 조건은 선택한 서비스와 수신자에 따라 달라집니다. 전송 전에 대상을 확인하고 취소할 수 있으며, 앱 안에서 삭제해도 외부 사본까지 지워지지는 않습니다.

국외 제공·위탁·보관은 같은 법적 관계로 일괄 취급하지 않습니다. 법령상 별도 동의나 공개·통지가 필요한 경우에는 해당 근거와 절차가 적용되며, 계약 이행에 필요한 위탁·보관의 근거를 모든 광고 제공에 일괄 적용하지 않습니다. 이 방침 열람이나 앱의 계속 사용을 국외 이전에 대한 포괄 동의로 취급하지 않습니다. 구체적 처리·권리 행사 문의는 help@devsworker.com으로 보내 주세요.

기기 잠금·업데이트와 백업 파일·암호·공유 대상을 관리해 주세요. 보호 기능이 모든 침해·자료 손실을 방지하거나 법적 증명력을 보장하지는 않습니다.
